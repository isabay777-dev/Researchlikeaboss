# Архитектура

Researchlikeaboss разделяет мышление и механику:

```text
рукопись + локальные источники
          │
          ├─ Docling (только по явной команде) ──> локальный Markdown
          ├─ PyAlex (только metadata-запрос) ────> компактный JSON
          │
          └─ deterministic pack ────────────────> EVIDENCE_PACK.md
                                                    │
                                                    v
                                                  Codex
                                                    │
                                                    v
                                  ACADEMIC_PUBLICATION_QA audit
```

Codex остаётся авторским и аналитическим слоем. CLI не делает выводов через LLM,
не отправляет рукопись внешнему провайдеру и не работает постоянно в фоне.

Состояние отдельной статьи хранится в `<article>/.researchops/`. Корпус и
извлечённые материалы не коммитятся в репозиторий Researchlikeaboss.
